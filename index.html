Contributing

Grow the lab through pull requests

New tutorials can start as Markdown files. A good contribution includes a clear topic, references, derivations where useful, and runnable source files when the topic later needs a visual experiment.

  1. Write Create a focused Markdown note under the content directory.
  2. Review Check formulas, terminology, references, and code formatting.
  3. Open PR Submit the article and update the homepage note index.
