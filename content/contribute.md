# 贡献须知

Computer Graphics Laboratory 接受围绕计算机图形学学习的内容贡献。当前网站以静态页面和 Markdown 为主，目标是让系列教程、推导、代码片段和参考资料可以被长期维护。

## 可以贡献什么

- 系列教程的新章节，例如光栅化、几何处理、渲染方程、采样与蒙特卡洛积分。
- 对现有文章的修正，包括公式、术语、错别字、代码格式和参考资料。
- 经过筛选的学习资源，例如书籍、课程、论文、工具和开源项目。
- 未来与 Paper 阅读、WebGL、WebGPU 或算法可视化相关的配套材料。

## 内容组织方式

系列教程放在 `content/series/<series-id>/` 目录下。每个系列目录需要包含一个 `series.yaml`，用于描述系列本身和章节列表。

| 文件 | 作用 |
| --- | --- |
| `series.yaml` | 系列元数据、主题、章节顺序 |
| `chapter-name.md` | 单篇 Markdown 章节 |
| `assets/` | 可选，存放该系列使用的图片或示意图 |

如果新增或调整系列目录，请运行目录生成脚本：

```sh
node scripts/build-library.js
```

该脚本会更新 `data/library.json`，Learn 页面会读取这个文件生成书架。

## 写作要求

- 文章应优先解释概念、推导和算法结构，而不是只堆放代码。
- 数学公式使用 LaTeX，例如 `$p' = K[R|t]p$` 或 `$$L_o = L_e + \int_\Omega f_r L_i \cos\theta_i d\omega_i$$`。
- 代码块需要标注语言，例如 ```` ```js ````、```` ```cpp ```` 或 ```` ```glsl ````。
- 引用外部资料时请给出来源链接或论文信息。
- 同一系列内尽量保持术语一致，例如 ray、sample、BRDF、rasterization 等词的译名。

## 提交 Pull Request 前

1. 确认 Markdown 可以被当前阅读器正常解析。
2. 如果修改了系列元数据，运行 `node scripts/build-library.js`。
3. 检查生成的 `data/library.json` 是否符合预期。
4. 在 Pull Request 描述中说明新增内容、修改范围和需要重点审阅的部分。

## 不适合直接合入的内容

- 没有来源的大段转载。
- 与计算机图形学学习无关的泛泛文章。
- 仅包含链接列表但没有筛选理由的资源集合。
- 无法在静态 GitHub Pages 环境中工作的依赖型页面。

> 贡献的重点不是一次写完一本书，而是让每一次改动都能被审阅、被链接、被后续维护。
